# Vídeos de Treinamento

Coloque aqui os arquivos de vídeo que devem ser exibidos aos operadores na aba **Treinamentos**.

## Como adicionar um vídeo

1. Copie o arquivo de vídeo para dentro desta pasta (`public/presentations/videos/`).
2. Pronto! O vídeo aparecerá automaticamente na aba de Treinamentos do operador.

## Formatos suportados

- `.mp4` (recomendado)
- `.webm`
- `.ogg` / `.ogv`
- `.mov`

## Dicas

- Prefira `.mp4` (codec H.264) para máxima compatibilidade com navegadores.
- O nome do arquivo é usado como título. Use hífens ou underscores no lugar de espaços,
  por exemplo: `procedimento-de-atendimento.mp4` será exibido como "procedimento de atendimento".
- Evite arquivos muito grandes (acima de ~100 MB) para não prejudicar o carregamento.
